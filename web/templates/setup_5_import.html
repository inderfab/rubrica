Bestehende Kontakte importieren

Falls bereits ein Adressbuch existiert: in Kontakte.app über Ablage → Exportieren → vCard exportieren eine oder mehrere `.vcf`-Dateien erzeugen und später über Import hochladen. Doppelte Kontakte werden automatisch erkannt und zusammengeführt, nichts wird überschrieben.

Dieser Schritt kann jederzeit später nachgeholt werden.
