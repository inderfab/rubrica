Bestehende Kontakte importieren

Direkt aus Kontakte.app übernehmen

Übernimmt alle Kontakte und Gruppen (als Ordner) aus der Kontakte.app auf diesem Rechner. macOS fragt beim ersten Mal nach Zugriff auf Kontakte – bitte erlauben. Doppelte Kontakte werden automatisch erkannt und zusammengeführt, nichts wird überschrieben. Bei sehr großen Adressbüchern (mehrere Tausend Kontakte) kann dieser Schritt einige Minuten dauern – die Seite bitte offen lassen, bis das Ergebnis erscheint.

Alternativ: in Kontakte.app über Ablage → Exportieren → vCard exportieren eine oder mehrere `.vcf`-Dateien erzeugen und später über Import hochladen.

Dieser Schritt kann jederzeit später nachgeholt werden.
